\# Java Swing Text Editor



A simple desktop-based text editor developed using \*\*Java Swing\*\*. The application provides basic text editing features through a user-friendly graphical interface.



\## Features



\* Create a new text file

\* Open an existing text file

\* Save a text file

\* Save As functionality

\* Edit and modify text

\* Cut, Copy and Paste

\* Select All

\* Simple and user-friendly GUI

\* Built using Java Swing



\## Technologies Used



\* \*\*Java\*\*

\* \*\*Java Swing\*\*

\* \*\*NetBeans IDE\*\*

\* \*\*Java Development Kit (JDK)\*\*

\## How to Run



1\. Clone or download this repository.

2\. Open the project in \*\*NetBeans IDE\*\*.

3\. Build the project.

4\. Run the project.

5\. The Java Swing Text Editor will open.



\## Purpose



This project was developed to practice \*\*Java GUI programming, event handling, file handling, and desktop application development\*\* using Java Swing.
